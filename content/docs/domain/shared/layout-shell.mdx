## Contract

`LayoutShell` 是可组合布局组件。它固定整体左右布局、左侧 nav 可收起、右侧顶部 nav link 区域；未传 `children` 时显示默认内容骨架，传入 `children` 后由下游页面承载真实业务内容。

下游页面可以用 `sidebarContent` 替换左侧默认 nav 区域，用 `headerContent` 替换标题区，用 `headerActions` 注入右上角操作区。`navItems` 和 `topLinks` 支持 `href`，也支持通过组件 props 上的 `onNavSelect` / `onTopLinkSelect` 接收选择事件。`collapsed` / `onCollapsedChange` 用于受控模式，`defaultCollapsed` 用于非受控初始状态。

```ts
export const layoutShellInputSchema = z.object({
  title: z.string().optional(),
  subtitle: z.string().optional(),
  sidebarTitle: z.string().optional(),
  collapsed: z.boolean().optional(),
  navItems: z.array(layoutShellNavItemSchema).optional(),
  topLinks: z.array(layoutShellNavItemSchema).optional(),
})
```
