DOE UI 第一版从三个 canonical examples 开始：

- `Button`：验证基础 UI 能力。
- `DataState`：验证 DOE 数据语义 / Data Semantics。
- `RoundContext`：验证 DOE 领域组合 / Domain Composition。

第一阶段刻意保持小范围：开发、展示、文档、发布 shadcn Registry、在全新 consumer app 中安装，并验证 AI 能复用已有组件，而不是重新实现。
