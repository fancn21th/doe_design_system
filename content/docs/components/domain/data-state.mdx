```tsx
export function Example() {
  return <DataState state="PARTIAL" />
}
```

## 语义规则 / Semantic Rules

`PARTIAL` 不等于 `NO_DATA`。

`NO_DATA` 不等于 `N/A`。

`N/A` 不等于 `0`。

Missing data 不能被转换成 zero。

## Schema

`DataState` 接收来自 `EvaluationStateSchema` 的值。

## 使用场景 / When To Use

在报告页面、Stage Observation、Data Quality Feedback 和 DOE Evaluation surfaces 中使用 `DataState`。
