# DOE Product Patterns

Patterns are reusable product compositions: they define hierarchy, layout, and
interaction affordances above a primitive but below a DOE business asset.

The first-round UI-alignment Patterns are:

- [MetricSnapshot](./metric-snapshot.md)
- [AnalysisPanel](./analysis-panel.md)

They define approved visual contracts for current alignment. Their reusable API
must still prove itself in another DOE context before being treated as stable,
cross-product assets.

When adding one, record its purpose, composition, states, accessibility needs,
accepted token usage, and known exclusions.
