## Contract

`Measurement` 是渲染边界：Canvas 分层绘制全量 die 点云、箱体统计量、规格线、整列选择与单 die 检视浮层。它不请求数据，也不解释 CP/Inline 的业务工作流。

### Readable plotting boundaries

- Analytical Surface 和滚动 viewport 必须服从消费方可用宽度；25 片 wafer 保留每列至少 68px，宽画布仅在组件内横向滚动。
- 纵轴标题与刻度使用独立区域。过长标题在画布上截断，完整 metric 保留在图表标题区；刻度文字限制在自身区域。
- 提供 `LOT_01` / `LOT_W01` 等带 wafer 序号的 group label 时，横轴使用 `W01` 简写；其他名称按列宽省略。Stage 同样按列宽省略。悬停整列显示完整 group 与 Stage / Step / Sequence / Condition，点击仍发送原始 `group.id`，die 浮层保留完整 label。
- 同值参考线共享 `LSL / Target` 等文字标注；近邻标注在纵向保持间隔，偏移标注连接到原始参考线。此排布只调整文字位置，绝不改变传入值、scale 或缺失值语义。

5173 report application is a read-only data upstream. The consuming app owns an adapter from its upstream DTO to this schema; this package neither imports nor modifies that application.

## Schema

```ts
export const measurementInputSchema = z.object({
  status: z.enum(["ready", "pending", "unavailable"]),
  metric: z.object({ id: z.string(), label: z.string(), unit: z.string().nullable().optional() }),
  groups: z.array(z.object({
    id: z.string(),
    label: z.string(),
    comparison: z.object({
      cohortId: z.string(),
      role: z.enum(["baseline", "variant"]),
    }).optional(),
    referenceLines: z.array(measurementReferenceLineSchema).optional(),
    summary: measurementSummarySchema,
    points: z.array(measurementPointSchema),
  })),
  referenceLines: z.array(measurementReferenceLineSchema).default([]),
})
```

Every group supplies its complete physical point cloud. `summary.count` must equal `points.length`; the component does not sample points. Keep Oracle/CP DTO details behind an application-owned adapter.

`comparison` is rendering metadata from that adapter: every group that should highlight together shares a `cohortId`; exactly one group in a cohort should use `role: "baseline"`, with the others using `"variant"`.

## Per-group references

`groups[].referenceLines` optionally supplies effective references for one wafer. They render as short lines inside that wafer column and participate in the default Y domain. The whole-chart `referenceLines` field is for references genuinely shared by all groups; consumers must not promote the first wafer's specification to a global line.

Effective limits and their availability belong to the upstream fact owner. Measurement never treats a raw zero as a missing limit, normalizes specifications, or recalculates capability. Consumers omit unavailable references. Group hover/die inspection keeps supplied labels and values available; absent group references preserve the existing contract.

## Interaction contract

- `onGroupSelect(groupId)` reports a whole wafer-column click without changing its visual state.
- Hovering a group with `comparison` facts highlights its whole cohort: `comparison.role: "baseline"` in blue and `"variant"` in teal.
- Hovering a die shows the die facts plus its group context and capability facts.

## Consumer state presentation

Optional `renderState(status)` receives `pending`, `unavailable`, or `empty` only
when Measurement cannot display a chart. The component continues to decide
that state from its parsed input and drawable domain. Report assets compose
this slot with ReportState via ReportMeasurement; other consumers retain their
existing default fallback. No statistics or evidence availability are redefined.
