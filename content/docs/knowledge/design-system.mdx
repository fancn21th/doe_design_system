DOE 产品设计系统的唯一权威入口是仓库根目录的 `DESIGN.md`；在本地仓库中请直接打开该文件。

它把以下内容从 Fumadocs 文档壳和 shadcn primitive 实现中分离出来：

- DOE visual language 与其原则；
- DOE-owned token 与 density contract；
- 可复用 Pattern 和 Domain visual asset 的准入边界；
- 参考模板、原型和截图如何被提炼为 DOE 规则。

Fumadocs 的导航、prose 样式、theme preset 与演示页面仅服务文档。shadcn 是实现基础层。两者都不是 DOE 产品设计规则的来源。
