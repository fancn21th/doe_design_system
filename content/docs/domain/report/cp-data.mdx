## Contract

`ReportCpData` 负责 CP Data report tab 的业务内容组合：可搜索的 CP Parameter 控制面与 shared `Measurement`。它以 `selection.parameterCode` 接收可选的 App 受控选择，并以 `onParameterChange` 发出选择意图；组件不请求数据，也不拥有 BFF、重试或路由工作流。未传入 `selection` 时，Component Lab scenario 可使用本地展示状态。

选择器与 `Measurement` 放在同一份 report 业务表面中，不增加仅承载选择器的外层 Card；当前参数不会在图表头部重复展示。

`Measurement` 使用单层中性 Analytical Surface：标题、范围、图例与分布证据按顺序呈现；画布宽度超出容器时在图表内部横向滚动。

图表卡片与滚动 viewport 的宽度必须保持在 report 内容范围内；25 片 wafer 采用每列至少 68px 的画布，1024 / 1280 / 1414px 页面均通过内部横向滚动查看。横轴采用可识别的 wafer 序号简写与按列宽省略的 Stage，完整来源身份保留于整列 hover、die 浮层与原始 `onGroupSelect(groupId)`。纵轴标题与刻度分区，同值/近邻规格文字按 shared Measurement contract 排布；规格值及后端统计不改变。

## Consumer handoff · POC

受控 `selection.parameterCode: null` 显示“请选择 CP Parameter”，参数控件仍可重新选择，旧图不会保留。
显式输入未提供 `measurement` 时绝不回退 scenario 数据；选中参数但无内容显示空态。
`measurement.groups[].capability` 接受 SOURCE CPK 及 `status` / `specSource`；提示消费 Backend 的 CPK 与不可计算状态，`cpu / cpl` 可选，组件不补算。

加载及无数据展示采用已通过 Split Table 验收的公共 `ReportState`：
无外框居中排版、18px 标题、浅色说明；最小高度 320px，紧凑子面板可缩到 160px。
所有加载状态只使用「正在加载报告数据」「请稍候，数据加载完成后将自动显示。」
及浅灰圆角底座中的 Spinner；空数据、未选择或筛选无结果只显示对应说明文字，
没有图标、Spinner 或 Cancel。状态事实与请求仍归 consumer 所有，缺失值不补为零。
