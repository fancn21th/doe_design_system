---
title: DOE Coding Rules
description: First AI-readable rules for using DOE UI components correctly.
---

1. Reuse existing domain components before creating new ones.
2. Do not convert `NO_DATA`, `N/A`, or missing values to zero.
3. Planned Condition must not be presented as Actual Condition.
4. Current Round Report is read-only.
5. Descriptive evidence must not be presented as causal conclusions.
6. Use `DataState` for DOE data and evaluation states.
