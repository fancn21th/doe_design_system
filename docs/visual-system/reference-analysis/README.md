# Reference Analysis

This directory stores evidence-only visual inventories of identifiable upstream
templates, prototypes, screenshots, or existing implementations.

An inventory records observable implementation facts, source locations, and
possible normalisation layers. It is not a DOE visual rule, token, Pattern, or
Domain contract. Follow the [Visual Rule Extraction Process](../extraction-process.md)
before promoting any candidate into its owning design-system document.
