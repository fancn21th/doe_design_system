title: 信息架构 / Information Architecture
description: DOE 最小业务闭环与文档边界。
---

DOE 应用需要清楚区分规划 / Planning、执行 / Execution、观测数据 / Observed Data 和分析 / Analysis。

## 业务闭环 / Business Loop

1. 定义 Round 边界。
2. 规划 Split Design 和 Planned Condition。
3. 执行并观察 Actual Condition。
4. 评估数据就绪度 / Data Readiness 和数据质量 / Data Quality。
5. 基于只读 Snapshot 分析 Current Round Facts。

Planned Condition 不能展示成 Actual Condition。Current Round Report 是只读分析视图，不应该表现成执行流程，也不是最终决策流程。
