## Contract

`ReportParameterMedian` 展示 CP parameter median 与 CPK matrix。

- 过滤区域使用 shadcn/base Input form pattern 和 Checkbox。`CP Parameter` 输入值通过 `onParameterQueryChange` 抛给外部业务状态；`仅显示 OOS` 通过 `onOosOnlyChange` 抛给外部业务状态。
- 组件不在内部过滤 `rows`，只渲染注入后的业务数据。docs 预览里的输入状态只用于保持控件可操作。
- Matrix 使用 shadcn/base Table，支持 sticky header 和 sticky first column，以保留宽表横向与纵向检查能力。
- `Mock LSL` / `Mock USL` 按原型字段展示，不视为生产规格。
- `OOS`、`CPK`、median value 均来自 fixture/schema，不在组件内部重算。

查询区使用无外框的紧凑控制行，只保留 CP Parameter、OOS 开关、结果数与控件自身边界；不重复展示标题、描述、状态图例或查询摘要。矩阵以自身边界和局部双向滚动作为唯一内容壳，其固定首列与表头只服务于宽表检视。

## Consumer handoff · SOURCE CPK

每个 cell 可携带 `capability: {cpk, status, specSource, lsl, usl, mean, sampleSigma, n}`。
正式规格 `specSource: "SOURCE"` 的 CPK 与现有 Mock OOS 分开显示；CPK 不参与现有 OOS / Yield context 判色。NULL CPK 显示缺值及输入状态，0、负数保留数值。
公式、样本范围、正式规格读取和状态判断均属于 Backend；组件只格式化输入，不能由 Median 推导 CPK。
`onParameterSelect(parameter)` 和 `onWaferCellSelect({parameter, waferId, cell})` 由 App 接到 CP Data / Parameter Map，组件不拥有跨 Tab 路由。
