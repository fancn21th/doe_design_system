## Contract

`ReportInlineData` 负责 Inline Data report tab 的展示组合：参数选择意图、共享
`Measurement`、wafer coverage、两种视图（箱型图 / parameter × wafer matrix）、raw-detail 状态和 source-provisional 限制。
矩阵单元格与箱型图共享同一组 `parameterId + waferId`：点击有数据的单元格会发出参数与 wafer 选择意图；弹出箱型图明细或切换应用工作流由 DOE App 决定。
它通过 callback 暴露参数/wafer 选择；请求、Snapshot 切换和重试属于 DOE App。

## Scenarios

- `normal`
- `matrix`
- `empty`
