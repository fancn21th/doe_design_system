## Contract

`ReportCpData` 负责 CP Data report tab 的业务内容组合：可搜索的 CP Parameter 控制面与 shared `Measurement`。它以 `selection.parameterCode` 接收可选的 App 受控选择，并以 `onParameterChange` 发出选择意图；组件不请求数据，也不拥有 BFF、重试或路由工作流。未传入 `selection` 时，Component Lab scenario 可使用本地展示状态。

选择器与 `Measurement` 放在同一份 report 业务表面中，不增加仅承载选择器的外层 Card；当前参数不会在图表头部重复展示。

`Measurement` 使用单层中性 Analytical Surface：标题、范围、图例与分布证据按顺序呈现；画布宽度超出容器时在图表内部横向滚动。

图表卡片与滚动 viewport 的宽度必须保持在 report 内容范围内；25 片 wafer 采用每列至少 68px 的画布，1024 / 1280 / 1414px 页面均通过内部横向滚动查看。横轴采用可识别的 wafer 序号简写与按列宽省略的 Stage，完整来源身份保留于整列 hover、die 浮层与原始 `onGroupSelect(groupId)`。纵轴标题与刻度分区，同值/近邻规格文字按 shared Measurement contract 排布；规格值及后端统计不改变。

## Consumer handoff · POC

受控 `selection.parameterCode: null` 显示“请选择 CP Parameter”，参数控件仍可重新选择，旧图不会保留。
显式输入未提供 `measurement` 时绝不回退 scenario 数据；选中参数但无内容显示空态。
`measurement.groups[].capability` 接受 SOURCE CPK 及 `status` / `specSource`；提示消费 Backend 的 CPK 与不可计算状态，`cpu / cpl` 可选，组件不补算。

## Stable comparison inspection · 2026-10-14

`measurement.groups` 每个完整 Wafer 身份只保存一份物理点云。可选 `measurement.comparisonGroups` 独立描述 Stage + Step + Sequence 的稳定 `id/stepKey`、显示 label、Variant 成员引用、BSL/Split 角色及 Condition。名称不能替代身份；完整组 roster 可以包含没有 CP 点数据的 Wafer，明细明确显示其缺失。

整列（含箱体与横轴）hover 展示该片参数的 可绘制点数、上游统计样本 N、Mean、Median、Sample σ、SOURCE CPK、CPU、CPL 和上游状态；只有靠近真实 die 才追加 die 值及已提供的 Final Bin / Die Result。缺失指标显示 `—`，缺失状态显示“未提供”，不派生 PASS/FAIL。

唯一归属的 hover 自动预览其组：BSL 列用蓝色、全部 Split 用绿色。共享 BSL 只沿用已明确选择且实际包含该片的比较组；无匹配上下文时只提示多归属数量，点击打开真实组选择。悬浮卡的位置受当前横向滚动窗口限制，不会被宽画布推出可见区域。图表上方只有一个“比较组”选择器，组件不隐式选第一组，也不合并不同 Step。选择、hover、明细与 zoom 都是局部状态，不请求数据。

点击 Wafer 打开对应 `BSL & Split Detail`。`detail.min/max`、`offscreenPointCount`、`totalPointCount`、status/reason 由 consumer 提供；范围未提供时保留不可用态。原始有限数值点的视野外计数和完整原始采集记录计数可能涵盖未绘制或无值记录，不应与过滤后的可绘制点数混同。组件不以局部视野重算能力、统计或计数。75%–300% 按钮/滚轮只缩放画布尺寸，复位为 100%，Esc 关闭。总览坐标包含已有 Mean±3σ 端点；固定明细坐标按上游范围裁剪图层。

新增 synthetic scenarios：`sharedBaseline`（同名 Step、不同 Seq、共享 BSL）、`missingCapability`（SOURCE NO_SPEC、缺 CPU/CPL 与 die 分类）、`unavailableDetail`。它们是交互测试数据，不是生产验收证据。
