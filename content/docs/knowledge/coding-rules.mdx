## Purpose

这页是 DOE Domain UI 的编码护栏。它把组件实现、文档维护、业务语义表达的硬约束收在一起，帮助开发者和 AI Coding Agent 在修改组件时保持同一条边界。

这页不是业务真相源，不替代原型、上游截图、ADR 或组件合同。遇到冲突时，先回到对应上游证据和 ADR，再更新本页。

## Sources

- `AGENTS.md`：仓库级执行规则。
- `CONTEXT.md`：Domain UI 项目的术语、边界和执行协议。
- `DESIGN_SYSTEM.md`：应用接入、shadcn foundation 和 density token 规则。
- `docs/adr/`：架构决策记录。
- `docs/practices/domain-ui-sizing.md`：业务表面尺寸和密度实践。
- `docs/upstream/components/`：业务组件切分的上游证据。

## Update Rule

只有当上游证据、ADR、设计系统约束或已确认的组件合同发生变化时，才更新本页。更新时要同步检查相关页面路径、组件文档、`CONTEXT.md` 和 `DESIGN_SYSTEM.md` 的引用。

当前业务组件按 `实验 / Trial`、`通用 / Shared`、`报告 / Report` 分类维护。规则更新时需要同时检查这些分类下的组件合同。

## Rules

1. 领域组件必须来自 `docs/upstream/components` 中确认过的业务切分；不要恢复旧的 `DataState`、`RoundContext` 或页面级组件。
2. 组件命名取上游路径最后一级或 report tab slug：`experiment`、`lot`、`steps`、`runcard`、`wafer`、`wafer-map`、`wafer-defect`、`runcard-history`、`history`、`report-*`。
3. 领域组件放在 `src/components/domain`；只通过稳定公共 API export。
4. 领域组件文档放在 `content/docs/domain/<category>`，例如 `trial`、`shared`、`report`。
5. 基础 UI 文档放在 `content/docs/ui`，暂时只做一级导航迁移，不新增维护范围。
6. MDX 文档至少保留 `预览 / Preview` 和 `Contract`；`Shadcn Components`、`Schema`、`Scenarios` 按组件复杂度补充。
7. Schema 是运行时入参契约。业务模型未确认前可以先使用空对象；一旦组件接入真实或 prototype-backed fixture，应同步补齐对应 schema。
8. shadcn 是本项目的基础设计系统层；基础 UI 控件必须使用原生 shadcn 组件，不要自写 Button、Input、Select、Dialog、Table、Tabs、Badge、Switch、Tooltip、Card 或 Dropdown Menu 的替代 React 组件、variant system 或 primitive abstraction。
9. 领域组件只能组合 shadcn 基础组件、业务 schema、fixtures/scenarios 和已确认的局部展示状态。会改变业务数据集、跨组件联动或请求 backend 的状态必须外置。
10. 领域组件尺寸必须通过 `.domain-ui-typography` 和 `src/app/globals.css` 中的 DOE density tokens 统一控制；不要在组件里用孤立的大号尺寸反复调视觉。
11. `text-xl`、`text-2xl`、`text-3xl`、`text-4xl`、`h-12`、`p-8`、`p-10`、`space-y-8` 不能作为普通业务组件默认尺寸；只有工作流起点、图表重点数值或 Modal 标题这类明确语义才允许使用。
12. 一个业务组件因局部交互渲染关联结果组件时，使用 `.domain-ui-related-stack`；间距由 `--doe-related-component-gap` 控制，不要在子组件上写临时 margin。
13. Step x Wafer 或 Report matrix 这类宽业务表格使用模块内部横向滚动；稳定列宽优先走语义 token 或明确的 min-width，不允许撑开页面。
14. 当 shadcn primitive 表现为业务卡片、tab、tile、证据图触发器、宽表或图表面板时，先读 `docs/practices/domain-ui-sizing.md`；使用语义 DOE token 和 utility 覆盖 slot 尺寸，不要写随机局部尺寸。
15. 领域组件不能直接调用 `fetch`、App Service、Gateway、Oracle/MES API 或任何真实提交函数。
16. `RunCard` 可以暴露 `onConfirm`、`onCancel`、`onChange` 等回调，但不能在内部执行 MES 下发。
17. `History` 可以本地过滤和选中实验，但不能决定应用路由。
18. 过滤控件的归属必须在组件合同里明确：纯本地展示筛选可以在组件内；会改变注入数据、跨 tab 联动或触发查询的过滤属于外部业务状态。
19. 不要把 `NO_DATA`、`N/A` 或 missing values 转换成 `0`。
20. Planned Condition 不能展示成 Actual Condition。
21. 描述性证据 / Descriptive Evidence 不能被展示成因果结论 / Causal Conclusion。
22. Observed Wafer Scope 不能被默认解释成 planned、released、executed 或 completed wafer scope。
23. Candidate Step Mapping 不能展示成 confirmed DOE Step mapping。
24. Mock、derived、deterministic-template、source-provisional、prototype-backed data 必须显式标记，不能伪装成 real production fact。
25. Coverage Unknown 不能展示成 pass、no issue 或 defect-free。
