## Contract

`WaferMap` consumes only `id`, `dies`, and precomputed `bounds`. Each die has an `id`, `x`, and `y`; Final Bin, parameter, defect, selection, and hover data are intentionally outside V1.

## Schema

```ts
export const waferMapDieSchema = z.object({
	id: z.string(),
	x: z.number().finite(),
	y: z.number().finite(),
})

export const waferMapBoundsSchema = z.object({
	minX: z.number().finite(),
	maxX: z.number().finite(),
	minY: z.number().finite(),
	maxY: z.number().finite(),
})

export const waferMapDataSchema = z.object({
	id: z.string(),
	dies: z.array(waferMapDieSchema),
	bounds: waferMapBoundsSchema,
})
```
