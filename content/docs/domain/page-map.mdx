## Mapping Rule

页面映射用于理解领域上下文，不等于当前 Domain UI 组件库必须实现页面 workflow。

Domain UI 组件可以复刻某个 surface 的局部业务对象、布局片段或局部交互，但不能拥有跨页面状态机、真实后端提交或应用路由。

## Boundary Notes

Stage Dashboard may provide snapshot input, but MES state and execution control belong in Experiment Execution Center.

Current Round Report is bounded by one read-only current-round snapshot and does not own MES Release, live stage status, Final DOE Report, formal RCA, Verdict, Action, Next Plan, or automatic next-round creation.

Round Review is the human decision layer after Current Round Report; the report provides review input, not final decisions.
