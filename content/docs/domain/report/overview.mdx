## Contract

`ReportOverview` 展示 report round 的摘要、KPI、异常晶圆明细、低良率、主要失效和参数异常入口。

## Layout roles

- 实验概览 KPI 使用中性 Metric Snapshot：label、可比较 value、明确 assessment 和 evidence 依序呈现；Card 只是承载实现，不使用无业务语义的渐变或阴影强调。
- 实验基础信息使用默认密度的 Analytical Surface；Metric Snapshot 与四组摘要卡使用紧凑密度。所有 Card 保持单层中性边界，不叠加 ring、阴影或装饰性填色。
- 明细表保持为直接的圆角表格面，不再嵌入第二层卡片，以保留多列内容的有效宽度。
