## Contract

来源：`doe-overview-ui` 提交 `7d066b6` 的已确认 UI。组件无数据时显示空状态，不隐式使用 fixture。

- 可折叠模块：实验基础信息、实验概览、当前轮次重点、主要失效组、低良率晶圆、参数异常提醒。
- 指标顺序：Round Weighted Yield、Median Wafer Yield、Average Wafer Yield、Wafer Count。
- 当前轮次重点输入 `focusItems`，展示 Wafer、Yield、Condition 和 Top Fail；消费者提供已筛选的有效记录，组件不判断阈值或关联工序。
- 参数提醒输入 `parameterAlerts`，展示参数与 OOS 晶圆数，悬停查看晶圆标识。OOS 是消费者提供的 Source median/spec 事实；不从 CPK 推导。
- 不再显示三个 Top 卡片及异常 Split Table 区块；旧输入字段兼容保留，不渲染。
- 窄屏模块纵向排列；重点文本换行，参数标签自动换行。数据请求、报告计算、跨页跳转不属于本组件。

## Scenarios

`normal` 为 prototype-backed 展示样例，`empty` 和 `partial` 表达缺失输入；不代表生产数据。
