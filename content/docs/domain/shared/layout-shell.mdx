## Contract

`LayoutShell` 是 layout-only domain asset：它负责 shadcn sidebar 的响应式、展开状态和侧栏/页头/主内容的空间关系；下游负责菜单、路由、用户信息和业务内容。

使用组合式 API，把 `Sidebar` 和 `Main` 放在根组件下；在 `Main` 内依次组合 `Header` 与 `Content`。需要由应用统一控制侧栏时，传入 `open` 与 `onOpenChange`；否则使用 `defaultOpen`。

Dashboard 内容仅是 fixture，用来验证布局能还原上游 `dashboard-01` 的视觉与行为，不属于 `LayoutShell` 的公开业务合同。
