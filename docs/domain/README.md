# DOE Domain Visual Assets

Domain visual assets express reusable DOE business concepts, such as a wafer
map, measurement view, split table, or experiment summary. They compose the
foundation and documented patterns while preserving a business data and local
interaction contract.

The existing component MDX pages, schemas, fixtures, and scenarios remain the
source of truth for a specific domain component. Add a page here only when a
cross-component visual rule has become stable; do not duplicate every component
contract in the design system.
