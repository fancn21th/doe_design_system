## 展示页 / Showcase

首页展示第一批三层能力：

- `Button`：普通 UI action。
- `DataState`：DOE 数据状态和 Evaluation State。
- `RoundContext`：当前 Round 的上下文摘要。

## 流程边界 / Flow Boundaries

当页面需要先建立 Round 边界再展示数据时，使用 `RoundContext`。当页面需要表达 Data Readiness、Data Quality、Evaluation Status 或缺失数据语义时，使用 `DataState`。
