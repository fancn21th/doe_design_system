## 用法 / Usage

```tsx
import { RoundContext } from "@/components/domain/round-context"

export function Example() {
  return (
    <RoundContext
      round={{
        id: "round-03",
        name: "Round 03",
        lot: "LOT-2408",
        splitVersion: "Split V3",
        waferCount: 25,
      }}
    />
  )
}
```

Round 表示一次 DOE iteration。

一个 Round 拥有自己的：

- Split design
- Execution
- Data
- Current-round analysis boundary

Current Round Report 等于一个 Round 加一个只读 Round Snapshot。
