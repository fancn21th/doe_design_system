## Contract

`ReportInlineData` 负责 Inline Data report tab 的展示组合：参数选择意图、共享
`Measurement`、wafer coverage、两种视图（箱型图 / parameter × wafer matrix）、raw-detail 状态和 source-provisional 限制。
矩阵单元格与箱型图共享同一组 `parameterId + waferId`：点击有数据的单元格会发出参数与 wafer 选择意图；弹出箱型图明细或切换应用工作流由 DOE App 决定。
它通过 `selection.parameterId` / `selection.waferId` 接收 App 受控选择，并通过 callback 暴露参数/wafer 选择意图；请求、Snapshot 切换和重试属于 DOE App。仅分布/矩阵视图切换保留为组件本地展示状态。

分布/矩阵视图切换作为独立的双图标控件呈现，不额外包裹标题 Analytical Surface；
分布/矩阵状态不改变 App 的选中参数或 wafer。分布视图以
parameter selector、Metric Snapshot、shared `Measurement` 与 wafer coverage 组织；矩阵视图保持独立的双向滚动表面，不嵌套外层分析卡片。选择色只表达当前参数或 wafer，不承担业务 assessment。
