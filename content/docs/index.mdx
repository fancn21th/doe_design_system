---
title: DOE UI
description: A small, AI-readable UI and domain foundation for DOE applications.
---

DOE UI starts with three canonical examples:

- `Button` validates the UI foundation.
- `DataState` validates DOE data semantics.
- `RoundContext` validates DOE domain composition.

The first phase is intentionally small: develop, showcase, document, publish a shadcn registry, install it into a fresh consumer app, and verify AI reuse.
