# Upstream Interactions

This directory stores observed prototype interaction flows before they are
distilled into component schemas, fixtures, scenarios, contracts, or ADRs.

Interaction notes are evidence. Prefer distilled scenarios and contracts for
implementation once they exist.

## Index

- `001-release-runcard-flow`: `下发配置` into RunCard release modal, RunCard selection/move/add behavior, and post-release execution state.
- `002-stage-dashboard-layer`: Stage Dashboard layer presentations, Stage selector behavior, fullscreen/export/close actions, and wafer evidence exploration.
- `003-wafer-defect-map`: Wafer defect selection, map point hover/select behavior, defect type distribution, image navigation, and defect detail modal.
