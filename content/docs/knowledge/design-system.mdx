DOE Domain UI 不是自建基础设计系统。基础控件来自 shadcn，本项目只在业务组件范围内增加 DOE 工作台密度 token。

## 设计语言优先级

本项目对 shadcn 的关注重点是完整的设计语言，而不只是单个组件：布局组合、字体层级、间距、控件尺寸、圆角、语义色、响应式节奏和交互状态都应保持一致。

本地上游 `/Users/fantianze/Vibe/g-working/g-doe/ui` 是该设计语言的 source of truth。引入 block 时先忠实同步其 layout 与 component composition；其中的业务文案、样例数据、账号和页面功能不是 DOE 设计事实，只有在用户确认适配时才替换。完整规则见 [UI Reference Refactor SOP](/docs/sop/ui-reference-refactor)。

## 应用接入入口

应用工程使用这套业务组件时，先读根目录：

- `DESIGN_SYSTEM.md`
- `CONTEXT.md`
- `docs/practices/domain-ui-sizing.md`
- `docs/adr/0008-use-shadcn-for-foundation-ui.md`
- `docs/adr/0009-layout-components-are-domain-assets.md`

应用侧必须把承载 DOE 业务组件的区域包在 `.domain-ui-typography` 下：

```tsx
<main className="domain-ui-typography">
  <Lot />
  <Steps />
  <RunCard />
</main>
```

## 基础层

- shadcn 是基础 UI 层。
- DOE Domain UI 不提供第二套 Button、Input、Select、Dialog、Table、Badge、Card。
- 领域组件只组合 shadcn primitive、业务 schema、fixtures/scenarios 和局部交互状态。

## shadcn Slot 覆盖

`.domain-ui-typography` 会统一约束这些 shadcn slot：

- `data-slot="card"`
- `data-slot="card-header"`
- `data-slot="card-footer"`
- `data-slot="card-title"`
- `data-slot="button"`
- `data-slot="input"`
- `data-slot="select-trigger"`
- `data-slot="textarea"`
- `data-slot="table"`
- `data-slot="table-head"`
- `data-slot="table-cell"`

## 关联组件栈

当一个业务组件因为局部交互渲染另一个关联结果组件时，使用语义 utility，不要给子组件写局部 margin：

```tsx
<div className="domain-ui-related-stack">
  <Steps />
  <RunCardHistory />
</div>
```

间距由 `--doe-related-component-gap` 控制，当前对齐原型模块间距 `16px`。

## 宽业务表格

Step x Wafer 这类表格天然比普通应用容器更宽。页面不应该被表格撑开，横向滚动应该收在业务模块内部：

```tsx
<div className="domain-ui-split-table-shell">
  <Table className="domain-ui-split-table" />
</div>
```

列宽由 `--doe-split-table-*-column` 系列 token 控制；组件可以用 `colgroup` 消费这些 token，避免在单元格上写一次性的宽度值。

## 业务表面尺寸

当 shadcn primitive 在领域组件中表现为业务卡片、tab、tile、证据图触发器、宽表或图表面板时，不要直接在 JSX 里拍局部尺寸。保留 shadcn primitive，把尺寸契约放进语义 token 和 utility。

例如证据图虽然用 `Button` 打开弹窗，但视觉上是图片预览面板，所以高度走 `--doe-defect-image-height`：

```css
.domain-ui-typography [data-slot="button"].domain-ui-defect-image-trigger {
  height: var(--doe-defect-image-height);
}
```

完整方法见 `docs/practices/domain-ui-sizing.md`。

## 禁止项

普通业务组件不要直接使用展示型尺寸作为默认样式：

```text
text-xl text-2xl text-3xl text-4xl
h-12 p-8 p-10 space-y-8
```

只有工作流起点、图表重点数值、Modal 标题这类明确语义可以使用较大 token。

## 验收方式

应用侧接入后，至少检查：

- 默认业务文本约为 `14px`
- dense table 文本约为 `12px`
- Input、Select、主要 Button 高度为 `40px`
- Split Table 行高为 `52px`
- Step x Wafer 宽表只在模块内部横向滚动，不撑开页面
- 业务模块标题为 `16px`
