## Contract

采纳 `doe-overview-ui@7d066b6` 的 Source Spec UI，保留 CPK 区间配色。

- 矩阵固定 Parameter / Unit 两列，后接 Wafer 列；不展示旧 Mock LSL、Mock USL、Mock Spec 列。
- 中位数、每片 Wafer 的规格、OOS 三态和 CPK 都由输入提供。缺规格或缺中位数表示不可评估，不冒充合格。
- `capability.cpk` 优先于旧 `cpk`；空值不回退。CPK < 1.33 红色，1.33 ≤ CPK < 1.67 橙色，其余中性；CPK 不改变 OOS 判定。
- 参数搜索与仅显示 OOS 沿用受控输入/callback，组件不发起数据请求。完整状态通过原组件提示保留。
- Parameter 160px、Unit 56px，每个 Wafer 144px；横向滚动，表头与参数列固定。

## Scenarios

normal、empty、unavailable、cpkThresholds、sourceCapability；fixture 是展示样例，不作真实业务结论。
