# DOE 页面 UI 验收标准

版本：v1.0 · 确认日期：2026-10-10

本文汇总用户在 Report Center 连续评审中明确确认的七类 UI 标准，作为后续 DOE 项目的设计、实现和验收参考。文档可独立阅读；Report Center 中的页面名只是打样示例，后续项目按自身业务命名。

本文属于 DOE Design System 的验收清单。字体、颜色、密度及组件合同仍由 [DESIGN](../../DESIGN.md)、[基础 tokens](../foundation/tokens.md) 和各专题规范负责；下列像素值是当前已认可主题和密度的基准。若以后调整密度，须同步更新基准与实际量测记录，不能只沿用相同类名便判定通过。

**七类标准：状态展示、容器对齐与留白、导航、业务 Block、筛选器、表格、图表。**

## 1. Loading / No Data

| 检查项 | 验收标准 |
| --- | --- |
| 容器 | 无外框，内容居中；主面板最小高度320px，紧凑列表或缺失 wafer 槽位160px。 |
| 加载图形 | 文字上方显示48px浅灰圆角底座与24px arc Spinner。 |
| 加载文案 | 标题「正在加载报告数据」；说明「请稍候，数据加载完成后将自动显示。」。 |
| No Data / 筛选无结果 | 仅显示符合当前数据来源、选择或筛选的文字，不显示图标、Spinner或按钮。 |
| 操作按钮 | 不显示Cancel。 |
| 字体和响应式 | 使用统一Empty标题/说明层级与主题中性色；长说明自然换行，减少动画偏好下停止旋转。 |
| 语义 | 加载、无数据、请求失败和数据不可用由真实状态决定，不能用相同外观掩盖不同业务含义。 |

后续项目可按业务对象替换说明；已确认的报告加载文案保持一致。组件只负责展示，请求、缓存及重试归消费者。

来源：[Split Table 状态合同](../../content/docs/domain/report/split-table.mdx)、ReportState。

## 2. 主视图容器对齐与外部留白

**对齐基准是 Header 内容容器。** 测量容器边界和 computed padding，不量图标、字形或按钮点击区；Sidebar切换按钮的负外边距不参与基准计算。

| 检查项 | 验收标准 |
| --- | --- |
| 左右边距 | 相对Main外框，视口≥1024px左右各24px；<1024px左右各16px。 |
| 共同边界 | 页面导航内容、Block、筛选区域及完整宽度的顶层表格/图表外框与Header内容区对齐。 |
| 首块上留白 | 页面导航外容器底部到首个正常内容容器顶部：视口≥768px为24px；<768px为16px。有BlockTitle时以标题容器顶部为准。 |
| 内外职责 | 卡片、单元格和绘图区保留自己的内部padding，不将内部内容误作主视图外框；避免外层与组件自身重复叠加顶部padding。 |
| 宽内容 | 宽表/密集图表在自身区域滚动，不撑大Main或产生页面横向溢出。 |
| 特殊状态 | Loading / No Data沿用相同正文起点；测量容器，不量居中文案顶部。错误提示有内容时单独记录其占位。 |
| 量测容差 | 布局边界允许1 CSS px误差；表格外框按外缘比较，不将1px边框误作偏差。 |

左右边距与上留白采用不同断点，不能统一简写为同一个「桌面断点」。复查侧栏开合、窄屏及局部横滚后的对齐。

## 3. 导航层级与 Tabs

原则：**相同语义层级使用同一个组件和样式规范；层级由切换范围决定。**

| 层级 | 作用 | 组件与样式 | Report Center示例 |
| --- | --- | --- | --- |
| 一级 | 全局功能入口 | 既有Sidebar与SidebarMenu；跨页面保持一致。 | 左侧模板库、知识库、实验入口 |
| 二级 | 页面切换 | 文字Tabs，左对齐。 | Overview、Split Table、Yield Analysis等 |
| 三级 | 页面或Block内主要视图 | 统一图标＋文字Tabs，左对齐，独立于标题行。 | CP Map / Defect Map / Overlay；箱型图 / 矩阵；候选分类 |
| 四级 | 三级视图内的子视图 | 纯文字line Tabs，位于三级下方、左对齐。 | Final Bin / Parameter Map |

- 二、三、四级的list与trigger水平方向padding和透明border均为0，首项图标/文字与内容左边界对齐。
- 项间距由右外边距提供：二级30px，三级/四级16px；末项0。不能删除内部padding后同时丢失项间距。
- 二级选中下划线与导航外容器底部分隔线重合，误差≤1 CSS px。
- 保留各级当前选中线、键盘焦点、方向键切换与受控callback；图标表达含义并保留文字，不仅依靠颜色。
- 导航过宽时在自身区域横滚，保持单行，不撑大主视图。
- Block内的主要视图导航依然属于三级。筛选、面包屑及操作按钮不因为位置变化成为新增导航层。

专题规范：[Navigation and blocks](navigation-and-blocks.md)。

## 4. 业务 Block 与 BlockTitle

Block是主视图内的业务单位，由上方header/title与下方body组成。一个页面可以有多个Block。

| 检查项 | 验收标准 |
| --- | --- |
| 标题组件 | 统一BlockTitle；语义h2、稳定且页面唯一的id，供锚点定位。 |
| 标题外观 | module-title：16px、字重600；主题前景色；长标题自然换行。 |
| 辅助信息 | 标题旁小问号，使用本地shadcn Base UI Tooltip；悬浮或键盘聚焦显示模块说明，Escape关闭。 |
| 标题/body间距 | 沿用已认可Wafer Split Table打样：14px（当前密度的gap-4结果）。 |
| 相邻Block间距 | 前一Block body底部到下一Block标题容器顶部24px。 |
| 首Block上间距 | 遵循第2节的24px/16px外部留白。 |
| 可见性 | body常驻显示；取消业务模块折叠容器、展开/收缩按钮、箭头及标题点击折叠。 |
| 分割线 | 不使用旧CardHeader造成的标题下装饰分割线，靠留白区分标题与正文。 |
| 帮助文案 | 简述模块、字段和已有交互；不推断统计事实，不隐藏必要数据或操作。 |

保留图表曲线显隐、wafer检视弹窗和下拉筛选展开；它们属于内容交互，不是业务模块折叠。导航选中下划线、表格边界和坐标网格线同样保留。

专题规范：[Navigation and blocks](navigation-and-blocks.md)、[BlockTitle合同](../../content/docs/domain/shared/block-title.mdx)。

## 5. 筛选器

**打样为CP × Inline的Step / All Steps。** 用户已明确要求用于其他Tab的筛选器验收。

| 检查项 | 验收标准 |
| --- | --- |
| 结构 | 标签在上，控件在下，两者左对齐。 |
| 标签 | 13px、字重400、行高20px，主题muted-foreground。 |
| 标签到控件 | 5.25px；当前gap-1.5的密度结果。 |
| 输入型控件 | 字号14px、字重400、高40px；边框1px、圆角10px；上下padding7px、左右12px。 |
| 内容 | 选择值/默认范围在左，下拉指示在右，长值不覆盖指示图标。 |
| 宽度 | 填满所在筛选列并随容器变化，不固定为示例列宽。 |
| 同行排列 | 各列标签及控件分别对齐；当前列间距10.5px（gap-3密度结果），项数随业务调整。 |
| 外围容器 | 裸筛选区域，无整体边框、背景或外层padding；保留控件自身边框。 |
| 窄屏 | 自然堆叠，不撑大主视图；常规输入型控件仍40px高。 |
| 状态 | 保留焦点、禁用、清除和已选择状态。 |

Select、可搜索Combobox、多选与Checkbox保留各自语义。按对应角色比较共同字体、表面、对齐及间距；不强行把复选框套成40px输入框，也不将全部筛选替换为单选。

专题规范：[Report filters](report-filters.md)。

## 6. 表格与分组悬停

**布局以Split Table为打样。** 比较实际计算样式，而非只比较类名。

| 检查项 | 验收标准 |
| --- | --- |
| 主文字 | 14px；主文字、次要说明和badge分别比较其设计角色，不将所有文字强制为14px。 |
| 表头 | 高40px，主题muted底色，左右padding8px。 |
| 正文单元格 | 四侧padding8px，行高随实际内容变化。 |
| 外框 | 1px主题边框、10px圆角；不再嵌套重复外框。 |
| 列宽/内容 | 按字段及可读性确定，不强行复制Split的列数；保留行、列、排序及数值。 |
| 滚动 | 宽表采用内部横/纵滚动，固定表头和固定列继续有效。 |
| 交互 | 筛选、链接、排序、tooltip、选择和键盘焦点仍可用。 |

| 指针位置 | 合并格 | 当前行普通格 | 同组其他行 | 相邻组 |
| --- | --- | --- | --- | --- |
| 合并格任意高度 | 高亮 | 高亮 | 高亮 | 不新增高亮 |
| 普通格/其中的链接或按钮 | 不新增高亮 | 高亮 | 不新增高亮 | 不新增高亮 |
| 离开表格 | 清除悬停 | 清除悬停 | 清除悬停 | 清除悬停 |

跨行、跨组以及从合并格切到普通格时即时切换，不能残留整组高亮。「不新增高亮」保留原有选中或焦点状态。分组与行身份使用真实稳定key，不能只用wafer ID。

相关规则：[Analytical surfaces](../foundation/analytical-surfaces.md)。

## 7. 图表容器、标题与内容边界

| 检查项 | 验收标准 |
| --- | --- |
| 外观 | 统一主题Card底色、细边框、圆角、轻阴影及内边距；标题、局部操作和图表属于同一外层容器。 |
| 标题 | 位于左上，16px/600、行高16px，主题前景色。 |
| 副标题 | 有业务副标题时位于标题下方、左对齐；14px/400、行高20px，muted-foreground；不编造说明。 |
| 标题/副标题间距 | 8px。 |
| 上部结构 | 左侧标题/副标题，右侧已有局部控件、图例或元数据；Block主要视图导航遵循第3节的左对齐规则。 |
| 图表上留白 | 完整标题区底部到图表viewport顶部48px＝Card布局gap24px＋内容padding-top24px。 |
| 桌面内边距 | 卡片顶部、左右和图表viewport底部到卡片内部底部均24px，扣除边框。 |
| 分割线 | Header border-bottom及Content border-top均为0；不加横向装饰分割线，坐标网格线保留。 |
| 自适应 | 绘图区跟随容器；轴、标签、数据标记和交互命中区域使用一致几何模型。 |
| 完整性 | 轴标题不重叠刻度；圆点/描边、顶部及底部标签完整显示，不以隐藏文字或修改尺度规避问题。 |
| 窄屏 | 标题与操作可换行；密集数据允许局部横滚；图表高度按业务类型确定，不照搬参考图固定尺寸。 |
| 折叠 | 不显示业务图表展开/收起，内容常驻。 |

图表viewport包含坐标轴与标签，间距不能按曲线或网格线位置计算。绘图引擎内部安全边距单独检查；Yield试点的12px仅是该SVG实现记录，不要求所有图表复制12px。

相关规则：[Analytical surfaces](../foundation/analytical-surfaces.md)、[Measurement合同](../../content/docs/domain/shared/measurement.mdx)。

## 8. 后续项目如何验收

1. 按七类要求逐页/逐视图检查；没有对应元素记N/A并说明，不以一页通过替代全部页面。
2. 记录实际视口、主题、密度、侧栏状态；使用同一CSS px坐标空间测量容器矩形、字体、padding、border和间距。
3. 保存对应截图与DOM量测；交互项检查真实键盘/指针路径。注明未覆盖的状态或交互。
4. 对每项记录PASS / FAIL / N/A、实测值与证据链接。标准、参考截图和已实现状态分开记录。
5. UI与Data分别验收：数据来源、规格、统计、NULL/0及去重有独立事实owner；页面外观正确不证明数据正确。

## 9. 范围及参考边界

- 初始四层导航示意图仅是参考；其中Sidebar240px、蓝色选中线及48/40/32px示意高度未成为通用验收值。
- Header内容容器是经过用户纠正并确认的对齐基准，不再采用Sidebar图标或点击区。
- 当前筛选器标准已建立，尚不能宣称其他Tab均已按此基准通过。图表试点包括Yield及CP Data相关修改，也不代表全部图表已统一。
- 后续项目复用这些视觉与信息架构规则；业务文案、字段、过滤语义和图表类型按项目实际确定。
